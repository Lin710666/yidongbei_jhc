## 组合推荐（按人群）

- **亲子家庭**：西溪湿地 → 宋城 → 良渚博物院（穿插亲子友好餐厅）
- **年轻情侣**：西湖环湖 → 龙井村 → 青芝坞夜生活
- **带老人**：西湖（平缓）→ 灵隐寺 → 河坊街（节奏慢、少步行）
- **朋友/团建**：九溪徒步 → 千岛湖 2 日游
