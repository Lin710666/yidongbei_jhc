# 文旅营销文案方法论（示例模板）

> 说明：供"营销素材生成"功能调用。含各平台文案公式、卖点提炼法、通用模板。

## 一、卖点提炼法（FAB）

对任意产品（景区/酒店/餐饮/文创），先按 **FAB** 提炼 3 个卖点：

- **F（Feature 特性）**：它是什么？（湖景房 / 现炒杭帮菜 / 千年古刹）
- **A（Advantage 优势）**：比同类好在哪里？（步行到西湖 / 30 年老字号 / 世界遗产）
- **B（Benefit 利益）**：给客人带来什么？（随手出片 / 一口地道 / 祈福许愿）

## 二、各平台文案公式

### 1. 小红书（种草）
```
【标题钩子】数字 + 情绪 + 悬念
  例：杭州 2 天怎么玩才不踩雷？这份攻略收好🔥
【正文】真实体验细节（时间/地点/费用/感受）+ 1-2 个"避坑"或"隐藏玩法"
【结尾】话题标签 3-5 个：#杭州旅游 #西湖 #周末去哪儿
```
特征：真实感、emoji、标签、突出"人无我有的细节"。

### 2. 朋友圈（亲切）
```
短句 + 情绪 + 配图引导
  例："西湖的晚霞，值回这一趟。#说走就走"
```
特征：口语化、短、有温度，像朋友分享，不过度营销。

### 3. 抖音（前三秒抓人）
```
开头钩子（3 秒内抛出冲突/悬念）→ 亮点罗列（快节奏）→ 结尾引导关注/收藏
  例："来杭州别只去西湖！这 3 个地方本地人才带你去——"
```
特征：口语、节奏快、引导互动。

### 4. OTA（携程/美团/飞猪，转化导向）
```
标题 = 核心卖点前置
  例：【湖景房】步行 5 分钟到断桥，含双早，周末不加价
正文 = 分点罗列卖点（位置/设施/服务/优惠）+ 用户证言
结尾 = CTA（"点击预订 / 收藏"）
```
特征：卖点前置、可信度、强 CTA。

### 5. 公众号（深度叙事）
```
引言（场景痛点）→ 分段小标题（产品故事/亮点/细节）→ 结尾转化
```
特征：叙事感、结构化、品牌调性。

## 三、通用模板（按产品类型）

### 景区
- 卖点：风光/文化/体验/交通/门票优惠
- 关键词：出片、遛娃、祈福、涨知识

### 酒店/民宿
- 卖点：位置/景观/设施/服务/价格/亲子
- 关键词：湖景房、私汤、亲子、管家、性价比

### 餐饮
- 卖点：口味/老字号/食材/环境/排队情况
- 关键词：地道、现炒、老字号、环境好、不踩雷

### 文创产品
- 卖点：文化符号/实用性/颜值/性价比/伴手礼属性
- 关键词：有故事的伴手礼、在地文化、送人有面子

## 四、A/B 测试建议

每次至少输出 **2 个不同角度**：
- 版本 A：偏"理性卖点"（罗列优势、数据、优惠）
- 版本 B：偏"感性情绪"（故事、氛围、共鸣）

运营者按数据（曝光/点击/转化）择优投放。
