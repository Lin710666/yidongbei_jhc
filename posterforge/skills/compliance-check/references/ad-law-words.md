# 广告法禁用与高风险词（B2B 物料通用）

依据《中华人民共和国广告法》，**文旅/酒店/餐饮**是投诉高发行业。
下表词表已内置在 `poster-forge/validate.py`，命中 `禁用` 列直接判失败。

## 一、绝对化用语（绝对禁止）

《广告法》第九条第（三）项：不得使用"国家级""最高级""最佳"等用语。

| 类别 | 词例 |
|---|---|
| 等级类 | 国家级、世界级、最高级、特级、顶级 |
| 比较类 | 最佳、最好、最优、最强、最便宜、最低价、最正宗、最好吃、最美 |
| 排序类 | 第一品牌、全国第一、全市第一、销量第一、排名第一、首家、独家 |
| 垄断类 | 绝无仅有、独一无二、仅此一家、填补空白 |
| 绝对承诺 | 百分百、100%、永久、终身、根治、特效、保证 |
| 权威暗示 | 国家免检、免检产品、央视上榜、国家认证（无证书时） |

**注意**：即使企业持有相关证明，**"最"字类仍属绝对禁止**，不存在豁免。
"首家/独家"可以举证使用，但举证责任在企业，风险高，建议一律避开。

## 二、需资质证明的表述（warning）

| 表述 | 需要什么 |
|---|---|
| 特级 / 极品 | 对应等级认定证书 |
| 首家 / 独家 | 可举证的时间或独家授权证明 |
| 领先 / 权威 | 第三方排名或认证 |
| 驰名商标 | 商标局认定文书 |
| 老字号 | 商务部门认定 |
| 国家 A 级景区 / 星级饭店 | 文旅部门评定文件 |
| 有机 / 绿色食品 | 对应认证标志 |
| 地理标志产品 | 地理标志专用标志 |

## 三、分行业高压线

### 酒店

- "温泉"：需地热矿水资质。加热自来水冒充温泉是明确违法。
- "海景房"：必须真能看到海。擦边表述（"可远眺"）要如实写。
- 价格：必须明确含/不含早餐、税费、服务费。"起"字要有更低房型支撑。

### 餐饮

- **医疗保健类表述一律禁止**：养生、滋补、药膳、治疗、缓解、增强免疫、排毒。
  普通食品不得暗示任何功效。
- "纯天然""无添加""零添加"：需符合国标定义，滥用会被罚。
- "现炒""现做"若为预制菜复热，属虚假宣传。

### 文旅

- 景区等级、非遗级别必须使用官方认定口径，不得自行提升或简写。
- 数据类表述（面积、客流量、年限）无来源一律不写。
- 活动"免费"须经主办方书面确认，不得由物料编辑推断。

## 四、安全替代写法

| 想表达 | 不要写 | 改写成（可核查的客观描述） |
|---|---|---|
| 好吃 | 全市最好吃 | 每日四点现熬汤底 |
| 便宜 | 全市最低价 | 午市套餐 ￥68 / 两位 |
| 高级 | 最高级客房 | 全海景露台房 45㎡ |
| 天然 | 100% 纯天然 | 当日现摘本地蔬菜 |
| 有效 | 根治失眠 | （删除，不得暗示功效） |
| 稀缺 | 独一无二 | 限量 200 间（须有库存依据） |

**原则**：把主观评价换成**可核查的客观事实**。既规避风险，又比形容词更可信。
