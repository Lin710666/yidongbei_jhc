# 食品宣传表述规范

餐饮物料的高压线比酒店、文旅更密。核心原因：**普通食品不得暗示任何功效**。

## 一、绝对禁止（无豁免）

### 医疗保健类

| 禁止 | 原因 |
|---|---|
| 治疗 / 治愈 / 疗效 | 医疗用语 |
| 缓解 / 改善（病症） | 暗示医疗效果 |
| 增强免疫 / 提高抵抗力 | 保健食品功能声称，普通食品禁用 |
| 排毒 / 养颜 / 抗衰老 | 保健功能暗示 |
| 药膳 / 食疗 | 医疗与食品界限模糊，高风险 |
| 防癌 / 抗癌 / 降三高 | 严重违法 |

**判断标准**：这句话能不能被理解成"吃了对身体某功能有好处"？能，就不能写。

### 绝对化用语

同 `compliance-check/references/ad-law-words.md`。
餐饮最常见的三个：**最好吃、最正宗、独家秘方**。

## 二、需资质或需举证

| 表述 | 要求 |
|---|---|
| 有机 / 绿色食品 / 无公害 | 对应认证标志，且在有效期内 |
| 纯天然 / 零添加 / 无添加 | 需符合国标对"添加"的定义，滥用常被判违法 |
| 野生 / 散养 / 土（鸡蛋、猪） | 需可溯源的养殖方式证明 |
| 和牛 / 伊比利亚黑猪 / 特定产区 | 产地证明 |
| 老字号 / 中华名小吃 | 官方认定 |
| 祖传 / 百年 | 无法举证，建议一律不用 |
| 现炒 / 现做 / 手工 | 若为预制菜复热，属虚假宣传 |

## 三、安全替代写法

| 想表达 | 不要写 | 改写成 |
|---|---|---|
| 味道好 | 全市最好吃 | 每日四点现熬牛骨汤 |
| 用料实在 | 料足量大 | 单份牛肉 120g |
| 新鲜 | 100% 新鲜 | 当日清晨直送 |
| 健康 | 养生又健康 | 少油少盐，可选不辣 |
| 独门 | 独家秘方 | 沿用 1998 年的配方 |
| 稀有 | 独一无二 | 每日限量 30 份 |
| 手工 | 纯手工制作 | 现擀现包 |

**原则**：主观评价 → 可核查的客观事实。数字、时间、工序比形容词可信，也更安全。

## 四、必填信息（漏了直接影响生意）

| 字段 | 为什么必须 |
|---|---|
| 营业时间 | 漏写会导致客人白跑，餐饮最常见的差评源 |
| 供应时段 | "午市 11:00–14:00" 比 "全天供应" 更准确 |
| 是否含茶位费/服务费 | 到店加价是投诉高发点 |
| 份量说明 | "两人份"需与客户确认实际分量 |
| 订座方式 | 电话 / 小程序 / 是否需要预约 |

## 五、图片规范

| 规则 | 说明 |
|---|---|
| **一律用实拍图** | AI 生成的菜品图与实物不符，属虚假宣传且极易被识破 |
| 不与实物差距过大 | 摆盘可以美化，但不能出现菜品里没有的食材 |
| 分量示意 | 若用特写显得很大，建议在文案标注实际克重 |
| 版权 | 用图需有授权，网络扒图风险高 |
