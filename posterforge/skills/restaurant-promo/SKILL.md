# Skill: restaurant-promo（饭馆）

## 服务对象与场景

餐馆、小吃店、茶饮、夜市摊位。典型需求：套餐海报、外卖头图、
团购页主图、门店引流。**特征：客单价低、转化靠"看起来值"，食品类表述受特别监管。**

## 提示词模板

```
你是餐饮营销物料编辑。根据以下素材产出物料内容。

【硬性约束】
1. 菜名、价格、份量、营业时间必须逐字使用我提供的信息。
2. 不得使用"最好吃""第一""独家秘方"等表述（违反《广告法》且易被同行投诉）。
3. 不得使用医疗/保健类表述（"养生""滋补""治疗""增强免疫"）——
   普通餐饮不得暗示功效，这是食品宣传的高压线。
4. 食材产地、等级（如"和牛""野生"）必须有据可查，否则不写。
5. 营业时间必须准确，写错会直接影响到店。

【素材】
店名：{{name}}
套餐内容：{{items}}      ← 逐条列出，如"四菜一汤 / 米饭例汤无限续"
价格：{{price}}
供应时段：{{hours}}
订座电话：{{phone}}
地址：{{address}}
招牌卖点：{{highlight}}  ← 如"当日现炒"

【输出】
PosterSpec JSON。套餐内容用 title 或 subtitle 分点呈现，
价格说明放 priceNote（如"工作日套餐价""起 / 两位"）。
```

## 版式与主题

| 用途 | 版式 | 主题 |
|---|---|---|
| 套餐海报 | `banner-horizontal-warm` | `warm` 暖橙（餐饮首选） |
| 夜市 / 烧烤 | `banner-horizontal-warm` | `plum` 紫红，夜感强 |
| 茶饮 / 轻食 | `poster-vertical-gold` | `pine` 松绿，清爽 |
| 团购主图（方图） | 横版 + `--overrides` | 按品类 |

暖橙系（`theme-sunset-warm`）是餐饮默认 —— 它触发食欲联想，且与食物照片不打架。

## 食品宣传的高压线

这几类表述**即使产品真有，也不能随便写**：

| 禁止表述 | 原因 |
|---|---|
| 养生 / 滋补 / 药膳 | 暗示保健功能 |
| 治疗 / 缓解 / 增强免疫 | 医疗用语，普通食品禁用 |
| 纯天然 / 无添加 / 零添加 | 需符合国标定义，滥用会被罚 |
| 有机 / 绿色食品 | 需认证标志 |
| 独家 / 首家 / 祖传 | 需资质，且"首家"极难举证 |
| 最好吃 / 最正宗 | 广告法"最"字类 |

**替代写法**：把主观评价换成**可核查的客观描述**：
"现炒" 而不是 "最好吃"；"每日四点现熬" 而不是 "滋补高汤"。

## 交付清单

- [ ] `validate.py --strict` 通过
- [ ] 菜名、价格、营业时间与客户确认一致
- [ ] 无医疗/保健类表述
- [ ] 无"最""第一""独家"类表述
- [ ] 供应时段已写明（午市/晚市，写错直接影响到店）
- [ ] 归档 spec + 成品

## 常见坑

| 坑 | 说明 |
|---|---|
| 营业时间漏写星期 | "11:00–14:00" 没写"仅工作日"，周末客人白跑 |
| 份量表述模糊 | "两人份"需与客户确认，写大了差评、写小了没人来 |
| 图片与实物不符 | 用 AI 生成菜品图风险极高，**餐饮物料一律用实拍图** |
| 价格未含茶位费 | 到店加价是最常见的投诉源 |
