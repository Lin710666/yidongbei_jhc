# 各平台物料尺寸速查

同一份 spec 通过 `--overrides` 改画布即可产出多尺寸。
**但竖版骨架硬撑成横版会显得空**，此时应换版式。

## 通用推荐

| 用途 | 尺寸 | 比例 | 做法 |
|---|---|---|---|
| 朋友圈 / 通用海报 | 1080×1440 | 3:4 | 竖版骨架直接出 |
| 朋友圈方图 | 1080×1080 | 1:1 | 竖版骨架 + overrides，检查留白 |
| 朋友圈全屏 | 1080×1920 | 9:16 | 竖版骨架 + overrides，或专用版式 |
| 公众号头图 | 900×383 | 2.35:1 | **换横版版式** |
| 通用横版 Banner | 1200×628 | 1.91:1 | `banner-horizontal-warm` |
| 小红书 | 1080×1350 | 4:5 | `checkin-photo-card` |

## 平台细则

### 微信

| 位置 | 尺寸 | 备注 |
|---|---|---|
| 公众号头图 | 900×383 | 安全区左右各留 20px |
| 公众号次图 | 200×200 | 方图裁切 |
| 朋友圈单图 | 1080×1440 或 1080×1080 | 竖图点击后全屏，信息量更大 |
| 朋友圈九宫格 | 1080×1080 | 单张被裁成方形展示 |

### 小红书

| 位置 | 尺寸 | 备注 |
|---|---|---|
| 图文笔记封面 | 1080×1350（4:5） | **官方推荐比例**，竖版占屏最多 |
| 视频封面 | 1080×1440（3:4） | |
| 方图 | 1080×1080 | 兼容但展示面积小于 4:5 |

小红书文案里**话题标签是流量入口**，每篇建议 2–5 个，一个地点相关 + 一个场景相关。

### 抖音 / 视频号

| 位置 | 尺寸 | 备注 |
|---|---|---|
| 视频封面 | 1080×1920（9:16） | 注意上下各留 260px 给 UI 遮挡 |
| 图文 | 1080×1440 | |
| 直播贴片 | 800×800 | |

### 美团 / 大众点评 / OTA

| 位置 | 尺寸 | 备注 |
|---|---|---|
| 门店头图 | 1200×628 或 750×400 | 横版 |
| 团购主图 | 800×800 | 方图，**文字要少**，缩略后要能看清 |
| 菜品图 | 800×800 | 一律用实拍，禁用 AI 生成 |
| 携程 / 美团酒店 | 1200×800（3:2） | 横版 |

## 批量出图脚本

```powershell
$py = 'E:\devenv\Scripts\python.exe'
$spec = 'specs\client-x.json'
$outdir = 'out\client-x'

$sizes = @(
  @{ n='vertical'; w=1080; h=1440 },
  @{ n='square';   w=1080; h=1080 },
  @{ n='story';    w=1080; h=1920 },
  @{ n='moment';   w=1080; h=1350 }
)
foreach ($s in $sizes) {
  $ov = '{"canvas":{"width":' + $s.w + ',"height":' + $s.h + '}}'
  & $py render.py --spec $spec --out "$outdir\$($s.n).png" --overrides $ov
}
```

**注意**：上表第 4 行（`moment` 1080×1350）是把竖版骨架压成 4:5，
如果主体（如大标题）被挤，应改用 `checkin-photo-card` 那种为 4:5 设计的骨架。
