# Skill: tourist-checkin（游客打卡模板）

## 服务对象与场景

**这是唯一面向 C 端（个人游客）的 skill。** 输入是游客的**对话 + 照片**，
产出是**可直接发小红书 / 朋友圈的打卡卡**。

与前三个 B2B skill 的根本差别：

| 维度 | B2B（文旅局/酒店/饭馆） | C 端（游客） |
|---|---|---|
| 审核方 | 客户要审、要合规 | 用户自己发，无审核 |
| 目标 | 促销转化 | **社交传播效果** |
| 文案风格 | 严谨、克制 | 口语、有情绪、带话题标签 |
| 版式 | `poster-vertical-gold` | `checkin-photo-card` |
| 合规重心 | 广告法 | 地点真实性、肖像权 |

## 输入怎么用

游客不会给你结构化数据，只会说"我昨天在大鹏看日出，拍了几张，想要能发小红书的"。
所以要从对话里抽取：

| 要抽的字段 | 从哪来 | 缺失时怎么办 |
|---|---|---|
| 地点 | 对话自述 | **必须问**，地点错等于白打卡 |
| 日期 | 对话自述 | 用今天，或问 |
| 照片 | 用户上传 | 必须有，否则退化成纯文字卡 |
| 情绪 / 亮点 | 对话里的形容 | 可直接用作 title |
| 同行人数 | 对话自述 | 可选，写进 body |
| 话题标签 | 由地点与场景生成 | 必给 2 个 |

**地点必须核实**（真实存在、名称正确）。这是唯一需要"事实核查"的字段 ——
游客自己也可能记错地名。

## 提示词模板

```
你是社交媒体文案助手。游客给了你一段描述和照片，请产出一张打卡图的内容。

【要求】
1. 标题（caption）不超过 16 字，可分两行，用 \\n 断开。要有情绪或画面感，
   不要"记录美好生活"这类空话。
2. 正文（body）不超过 3 行、每行不超过 20 字。写一个具体的细节
   （时间、走路几分钟、哪家店），具体细节比形容词更能获得互动。
3. 话题标签 2 个：一个地点相关（如"#大鹏所城"），一个场景相关（如"#海边日出"）。
4. 不得编造游客未提及的信息（同行人数、消费金额、天气）。
5. 语感：像朋友发的，不像广告。**不要用感叹号堆砌。**

【游客原话】
{{user_dialogue}}

【照片信息】
{{photo_desc}}   ← 若无法识别照片内容，写"用户上传的照片"

【输出】
PosterSpec JSON，layout 用 @layout:checkin-photo-card。
```

## 版式：`checkin-photo-card`

1080×1350（4:5，小红书最优比例）。结构：

```
地点标签 (topLabel)          日期 (topDate)
┌──────────────────────────────────┐
│           照片（photo）            │  ← 占 52% 高度，圆角 3.5%
│        白色细描边 photoFrame        │
└──────────────────────────────────┘
标题 (caption)  ← heavy 56px，最多 3 行
正文 (body)     ← sans 28px，最多 3 行
[#标签1] [#标签2]              PosterForge 水印
```

**照片是这个 skill 的主角**，文字只做点缀。所以：
- `fit: "cover"` 保证不变形
- 圆角 + 白描边让照片"贴"在版面上，而不是裸露
- 文字压在深色底上，不用阴影也读得清

## 照片处理建议

| 情况 | 处理 |
|---|---|
| 照片是竖构图 | 直接放，`cover` 会裁上下，检查主体是否被裁 |
| 照片主体偏一侧 | 调 `box` 位置，或在版式层面加偏移 |
| 照片很亮 | 降低 `caption` 的字号，或加深背景 |
| 多张照片 | 当前版式只支持一张。多图需求要用 `tiles` 的横排版式（未实现） |
| 人像照片 | **必须确认用户同意公开**，涉及肖像权 |

## 交付清单

- [ ] 地点名称真实且拼写正确（已核实）
- [ ] 日期与用户所述一致
- [ ] 标题 ≤ 16 字，有具体画面感
- [ ] 正文含至少一个具体细节
- [ ] 2 个话题标签，一个地点一个场景
- [ ] 未编造用户未提及的信息
- [ ] 人像照片已获用户同意

## 已知限制

- **图片上传接口未实现**：当前 `photo` 图层指向示例图，
  接真实照片需要给站点服务器加一个上传端点（`POST /api/upload`）
- 仅支持单图。多图九宫格版式未实现
- 未做照片自动方向校正（EXIF 旋转）
