# 小红书风格打卡文案指南

游客打卡的目标是**社交传播**，不是信息传达。所以写法与 B2B 物料完全相反。

## 一、标题（caption）

**上限 16 字**，可分两行（`\n`）。

### 有效模式

| 模式 | 例 |
|---|---|
| 时间 + 反差画面 | `五点半的海，\n值得早起一次` |
| 具体动作 + 感受 | `骑了 20 公里，\n腿废了但值` |
| 意外发现 | `本来只想歇脚，\n结果坐了一下午` |
| 数字 + 具体 | `第 3 次来，\n还是点了同一碗` |

### 无效写法（等于没写）

| 不要写 | 为什么 |
|---|---|
| 记录美好生活 | 空话，零信息量 |
| 美好的一天 | 同上 |
| 打卡 XXX | "打卡"二字不带来任何画面 |
| 太美了！！！ | 形容词堆砌 + 感叹号，像广告 |
| 今天很开心 | 无具体信息 |

**判断标准**：读者能不能从标题里"看见"一个画面？看不见就是空话。

## 二、正文（body）

**最多 3 行，每行 ≤ 20 字。**

核心原则：**写具体细节，不写形容词。**

| 形容词写法 | 具体写法 |
|---|---|
| 风景很美 | 从民宿走过去 8 分钟 |
| 东西很好吃 | 停车场旁那家肠粉六点就开了 |
| 人很多 | 五点半到的时候已经站了两排三脚架 |
| 天气不错 | 风大，记得带件外套 |

具体细节（时间、距离、店名、价格）比形容词更能获得互动，
因为它"可用"—— 别人能照着做。

## 三、话题标签

**2–5 个**，结构建议：

| 类型 | 例 | 作用 |
|---|---|---|
| 地点标签 | #大鹏所城 #东极岛 | 进入地点流量池 |
| 场景标签 | #海边日出 #citywalk | 进入兴趣流量池 |
| 品类标签 | #深圳周边游 #周末去哪儿 | 大流量池，竞争激烈 |
| 节日标签 | #国庆去哪儿 | 时效性流量，节前一周最有效 |

**别堆无关标签** —— 会被判定为流量作弊，反而降权。

## 四、语感检查

发之前读一遍，问三个问题：

1. **像朋友发的，还是像广告？** —— 出现"欢迎光临""期待您的到来"就是广告腔。
2. **有没有感叹号堆砌？** —— 一行超过一个感叹号就该删。
3. **有没有假大空的词？** —— 美好、惬意、绝美、治愈，这些词删掉不影响信息量。

## 五、图片

| 要点 | 说明 |
|---|---|
| 比例 | 4:5（1080×1350）占屏最多 |
| 首图 | 决定点击率。有主体、有光影的实拍胜过滤镜浓重的 |
| 排版图 | 首图若加文字排版，字号要大，缩略状态要能看清 |
| 人物出镜 | **必须获得本人同意**，涉及肖像权 |
| 数量 | 3–9 张，首图 + 细节 + 环境 |

## 六、合规提醒

游客打卡看似无监管，但以下仍要注意：

- **地点真实性**：不能标成没去过的地方，平台会核验定位
- **肖像权**：拍到路人且可辨识，建议虚化或征得同意
- **商业推广**：若为商单，必须按平台要求标注"合作"
- **不实信息**："免费""无需预约"等若为假，会引发纠纷
