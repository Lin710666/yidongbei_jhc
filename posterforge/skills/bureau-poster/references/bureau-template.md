# 文旅局物料模板要点

## 风格取向

文旅局物料与商业物料的根本差别：**它在传递官方信息，不是在推销。**

| 维度 | 做法 |
|---|---|
| 配色 | 深青金 / 松绿 / 传统色系，**避开高饱和促销红** |
| 字体 | 标题用 `heavy`（黑体）或 `zhong`（华文中宋），正文用 `sans` |
| 留白 | 比商业物料多 30% 以上，显庄重 |
| 装饰 | 开四角装饰线（`theme.ornaments`） |
| 语气 | 陈述句为主，不用感叹号 |
| 元素 | 主办单位、承办单位署名完整；无二维码时可留咨询电话 |

## 必备信息清单

缺任何一项都不能交付：

- [ ] 活动全称（与官方通知**逐字一致**，不得简写）
- [ ] 主办单位
- [ ] 承办 / 协办单位（如官方通知中有）
- [ ] 起止时间（含年份）
- [ ] 地点（完整地址，不只写景区名）
- [ ] 咨询电话（必须能接通）
- [ ] 票务信息（免费 / 收费 / 预约方式）
- [ ] 有效期或活动截止日

## 版式结构建议

```
品牌区    brand        → 主办单位或活动主视觉名
副标题    eyebrow      → 活动定语，如"2026 年秋季 · 公益惠民"
主标题    title        → 活动全称的核心词（≤ 8 字，硬换行）
说明      subtitle     → 时间、地点、主要内容（2–3 行）
信息条    pricePanel   → 票务信息（免费则写"免费开放"）
联系      phone/address
页脚      footerNote   → "以官方发布为准" 或主办方落款
```

## 提示词要点

给 LLM 的提示里必须包含这段约束：

```
以下信息必须逐字使用，不得改写、优化、精简或扩写：
  活动名称 / 时间 / 地点 / 主办单位 / 票务
不得添加我未提供的任何承诺性表述（免费、保证、名额充足等）
不得使用"最"字类表述
数据类表述若无来源则一律不写
```

**"不得改写"这条最容易被执行偏**：模型会本能地把"XX 市 2026 年秋季文化旅游节"
"优化"成"XX 秋季文旅节"，而官方物料里名称必须完整。

## 常见返工原因

| 原因 | 预防 |
|---|---|
| 活动名称被简写 | 提示词里明确"逐字使用"，交付前逐字比对 |
| 时间漏了年份 | 时间字段要求写全（2026 年 10 月 1 日–7 日） |
| 地点只写景区名 | 要求写完整地址 |
| 用了促销红/金 | 用 `theme-deep-teal-gold` 而非 `warm` |
| 出现"欢迎广大市民踊跃参加" | 官腔套话，删掉；改为具体信息 |
| 主办方署名缺失 | 交付清单逐项核 |
