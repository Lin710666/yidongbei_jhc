# Skill: bureau-poster（文旅局）

## 服务对象与场景

文旅局、文化馆、景区管理方。典型需求：节庆活动预告、景区票务推广、非遗宣传、
城市形象物料。**特征：需报批、口径严谨、风格偏稳重。**

## 与其它 skill 的差别

| 维度 | 文旅局 | 酒店/饭馆 |
|---|---|---|
| 口径 | **必须以官方发布为准**，不得润色 | 可营销化表达 |
| 风格 | 稳重、留白多、少用感叹 | 强促销、价格前置 |
| 版式 | `poster-vertical-gold` + 四角装饰线 | 可用暖色/高对比 |
| 审核 | 双重：合规 + 内部报批 | 合规 |

## 提示词模板

```
你是文旅局宣传物料的文案编辑。根据以下素材，产出物料内容。

【硬性约束】
1. 活动名称、时间、地点、主办方必须逐字使用我提供的信息，不得改写或"优化"。
2. 不得使用任何《广告法》禁用词（国家级/最高级/第一/最低价等）。
3. 不得添加我未提供的承诺（如"免费""保证""名额充足"）。
4. 数据类表述（如面积、客流量、历史年限）若无来源则一律不写。

【素材】
活动名称：{{name}}
主办单位：{{organizer}}
时间：{{time}}
地点：{{place}}
活动内容：{{details}}
咨询电话：{{phone}}

【输出】
严格按 PosterSpec 契约输出 JSON。字段：
  meta.client / meta.intent / meta.facts_source（写"由文旅局 {{date}} 提供"）
  layers 中的 brand / eyebrow / title / subtitle / phone / address / footerNote
```

## 版式建议

| 用途 | 版式 | 说明 |
|---|---|---|
| 活动预告海报 | `poster-vertical-gold` | 竖版 1080×1440，加四角装饰线显正式 |
| 公众号头图 | `banner-horizontal-warm` | 横版 1200×628 |
| 朋友圈方图 | 竖版 + `--overrides` 改 1080×1080 | 检查留白 |

## 主题色

深青金（`theme-deep-teal-gold`）适合政务与文博。
景区类可用 `pine`（松绿）系；节庆可用 `plum`（紫红）系，但**不要用高饱和促销红** —— 那是商业物料语言。

## 交付清单

- [ ] `validate.py --strict` 通过（正式物料不开严格模式会漏 warning）
- [ ] 活动名称 / 时间 / 地点与官方通知逐字一致
- [ ] 主办方、承办方署名完整
- [ ] 未出现未经批准的承诺性表述
- [ ] 咨询电话可接通
- [ ] 归档 `.spec.json` 与成品 PNG

## 反例（会被校验器或人工拦下）

| 错误示例 | 问题 |
|---|---|
| "全市最美的赏花地" | 广告法禁用词"最" |
| "预计接待游客 10 万人次" | 数据无来源 |
| "国家级非遗项目" | 需资质证明，且非遗级别有官方认定口径 |
| "免费入园" | 未经确认的承诺 |
