# 文旅智能辅助 Skill（wenlv-assistant）

> 题目编号：JBGS-2026-06 ｜ 题目名称：文旅智能辅助场景
> 基于 AI Coding / OpenClaw 引擎规范的轻量化文旅智能 Skill 系统。

## 一、项目简介

面向文旅行业 **景区、酒店、餐饮** 三大核心业态，针对
**消费体验同质化、客源转化效率低、产品创新迭代慢** 三大痛点，
用「智能适配、创新迭代、精准创收」重构传统「人工服务、固化产品、被动经营」的运营模式。

聚焦 **两大核心功能（做深不做宽）**：

| 核心功能 | 解决痛点 | 对应价值 |
| --- | --- | --- |
| ① 个性化方案规划 | 消费体验同质化 | 游客消费体验升级 |
| ② 文旅营销素材生成 | 客源转化效率低 / 营销获客成本高 | 文旅营销创收增效 |

## 二、一键部署教程

### 方式 A：体验 HTML 演示界面（零门槛，推荐先试）

> 纯本地、零依赖、零安装，双击即用。

1. 打开 `demo/index.html`（双击即可，无需任何服务器 / 依赖）
2. 切换「🗺️ 方案规划」/「✍️ 营销素材生成」两个 Tab
3. 选择需求 → 点击「生成」→ 点击「导出 Markdown」保存结果

### 方式 B：部署 Skill（供 AI Coding / OpenClaw 引擎调用）

1. 将 `.agents/skills/wenlv-assistant/` 目录整体拷贝到引擎的 skills 目录
2. 引擎会自动识别 `SKILL.md`（含 name / description 元信息）
3. 按需替换 `references/` 下 4 个样本库为本地真实业态数据
4. 用户直接以自然语言触发，如：
   - 「帮我安排杭州 2 天行程，带父母，预算舒适」
   - 「为我家西湖边的民宿写一条小红书文案」

**环境要求**：无特殊依赖；HTML 演示仅需现代浏览器，Skill 仅需支持 SKILL.md 规范的引擎。

## 三、功能说明

### 功能一：个性化方案规划
输入目的地、天数、预算、同行人群、兴趣偏好、饮食禁忌，
输出「游玩·旅居·餐饮」一体化方案，含：
行程总览表、逐日行程（上午→午餐→下午→晚餐→住宿→交通贴士）、
费用预估、替代方案与避坑提示。

### 功能二：文旅营销素材生成
输入产品类型、目标平台、客群、风格，
输出 2 个可 A/B 测试的版本（理性卖点版 + 感性情绪版），含：
标题、正文、话题标签、配图建议、行动号召（CTA）。
覆盖朋友圈 / 小红书 / 抖音 / OTA / 公众号 五大平台。

## 六、异常处理设计

| 异常类型 | 处理方式 |
| --- | --- |
| 信息缺失 | 必填项一次性集中追问（带可点选选项）；可选项用默认值并注明 |
| 目的地不在样本库 | 退回通用文旅知识生成，并明确标注「建议补充本地数据」 |
| 数据读取失败 / 网络异常 | 降级为通用知识生成，并告知「当前未读取到本地样本库」 |
| 输入矛盾（预算与需求冲突） | 指出冲突点，给出「加预算 / 降需求」两套方案 |
| 越界 / 无关请求 | 礼貌说明本 Skill 聚焦范围，不处理无关任务 |

## 七、数据安全与本地化

- **全程本地处理**，演示界面与 Skill 均不将数据上传至任何云端
- **一键导出** Markdown，结果可本地保存、二次编辑
- 样本库均为**示例数据**，正式运营时替换为本地真实业态数据即可无缝切换
