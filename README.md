# 文旅智能辅助 Skill（wenlv-assistant）

> 题目编号：JBGS-2026-06 ｜ 题目名称：文旅智能辅助场景
> 基于 **本地开源大模型（Ollama）** 驱动的文旅智能 Skill 系统。

## 一、项目简介

面向文旅行业 **景区、酒店、餐饮** 三大核心业态，针对
**消费体验同质化、客源转化效率低、产品创新迭代慢** 三大痛点，
用「智能适配、创新迭代、精准创收」重构传统「人工服务、固化产品、被动经营」的运营模式。

聚焦 **两大核心功能（做深不做宽）**：

| 核心功能 | 解决痛点 | 对应价值 |
| --- | --- | --- |
| ① 个性化方案规划 | 消费体验同质化 | 游客消费体验升级 |
| ② 文旅营销素材生成 | 客源转化效率低 / 营销获客成本高 | 文旅营销创收增效 |

**核心特点：真正的本地部署 + 真 AI**。所有方案与文案均由**本机运行的开源大模型**生成
（非规则模板、非云端 API），数据全程不出本机，结果可一键导出为 Markdown。

## 二、部署教程（本地大模型）

### 前置条件（仅需安装一次）

| 依赖 | 用途 | 安装方式 |
| --- | --- | --- |
| [Ollama](https://ollama.com) | 本地大模型推理引擎 | `winget install Ollama.Ollama` |
| [Node.js](https://nodejs.org) ≥ 18 | 本地服务器 | 官网下载安装 |
| 模型 `qwen2.5:7b` | 中文文旅生成模型（约 4.7GB） | `ollama pull qwen2.5:7b` |

### 一键启动（推荐）

双击 `start.bat`，脚本会自动：检查 Ollama → 缺失则下载模型 → 启动服务器 → 打开浏览器。

### 手动启动

```bash
ollama pull qwen2.5:7b   # 首次需下载模型
node server.js           # 启动本地服务器
# 浏览器打开 http://localhost:8000
```

## 三、技术架构（实现原理）

```
浏览器 demo/index.html（采集表单 → 展示/报错）
   │  POST /api/generate
   ▼
本地服务器 server.js（Node，localhost:8000）
   │  ① 读取 .agents/skills/wenlv-assistant/SKILL.md + references/*.md
   │  ② 组装成"系统提示词"（说明书 + 本地知识库）
   │  ③ POST localhost:11434/api/chat
   ▼
Ollama 本地推理（localhost:11434，加载 qwen2.5:7b）
   └─ 模型真正"理解需求 + 生成"，返回 Markdown
```

**一个 Skill 的完整形态 = 说明书（SKILL.md）+ 知识库（references）+ 大脑（本地模型）。**
本项目把三者真正串了起来：`SKILL.md` 不再是一张"纸"，而是被 `server.js` 读进内存、
拼成系统提示词喂给本地模型；`references/*.md` 作为可替换的本地样本库，让模型输出可落地。

## 四、功能说明

### 功能一：个性化方案规划
输入目的地、天数、预算、同行人群、兴趣偏好、饮食禁忌，
由本地大模型生成「游玩·旅居·餐饮」一体化方案，含：
行程总览表、逐日行程、费用预估、替代方案与避坑提示。

### 功能二：文旅营销素材生成
输入产品类型、目标平台、客群、风格，
由本地大模型生成 2 个可 A/B 测试的版本（理性卖点版 + 感性情绪版），含：
标题、正文、话题标签、配图建议、行动号召（CTA）。
覆盖朋友圈 / 小红书 / 抖音 / OTA / 公众号 五大平台。

## 七、异常处理设计

**系统级异常**（由 server.js / 前端处理，出错直接提示用户）：

| 异常类型 | 处理方式 |
| --- | --- |
| Ollama 未安装/未运行 | 返回「请确认 Ollama 已安装并运行」及安装命令 |
| 模型未下载 | 返回「请运行 `ollama pull qwen2.5:7b`」 |
| 未启动本地服务器 | 前端提示「请用 start.bat 或 node server.js 启动」 |
| 模型返回为空 | 提示重试 |

**模型级异常**（由 SKILL.md 提示词约束模型行为）：

| 异常类型 | 处理方式 |
| --- | --- |
| 信息缺失 | 必填项一次性集中追问（带选项） |
| 目的地不在样本库 | 退回通用文旅知识生成，并标注「建议补充本地数据」 |
| 输入矛盾（预算与需求冲突） | 指出冲突点，给出两套方案 |
| 越界/无关请求 | 礼貌说明聚焦范围 |
| 危险/不当内容 | 拒绝生成并说明理由 |

## 八、数据安全与本地化

- **推理全程在本机**：模型（Ollama）与数据都不出本机，**不调用任何云端 API**
- **一键导出** Markdown：结果可本地保存、二次编辑
- **样本库可替换**：`references/` 下均为示例数据，正式运营替换为本地真实业态数据即可
- 如需更换模型（更快/更强/更省内存），改 `server.js` 顶部的 `MODEL` 常量即可
