## 说明

本仓库是网页版本体，包含完整的源代码、技能包与测试。

同一项目还有一份配套的 AIRI 侧改进（在 Project AIRI 源码上新增文旅页面，并加一个把本机
Qwen TTS 适配成 OpenAI 兼容接口的服务桥）。那份工作不在本仓库内。上面的文档里凡是提到
「交付物 ① / AIRI 改进版 / airi/ 目录」的段落，说的都是那部分，阅读时可以直接跳过。

只想部署本仓库的话，看 [部署教程.md](部署教程.md) 里的「第 0 步 ~ 第 4 步」即可。
