# 一键部署教程

> 项目：文旅智能辅助 Skill ｜ 题目编号：JBGS-2026-06 ｜ 题目名称：文旅智能辅助场景

这是一份面向第一次接触本项目的人（评审老师、同学、试用者）的部署说明。
照着做，大约 10 分钟可以在本机跑起来，其中大部分时间花在下载模型上。

项目零第三方依赖，不需要任何账号，也不需要联网调用 AI 服务——配置完成后可以断网运行。

---

## 一、环境要求

| 依赖 | 版本要求 | 用途 | 说明 |
| --- | --- | --- | --- |
| **Windows** | 10 / 11 | 运行环境 | 本项目主要在 Windows 上验证（Linux/macOS 可用 `node server.js` 启动） |
| **Node.js** | **≥ 18** | 本地服务器 | [官网下载](https://nodejs.org) 安装即可，无其他 npm 依赖 |
| **Ollama** | 任意近期版本 | 本地大模型推理引擎 | 一条命令安装：`winget install Ollama.Ollama` |
| **模型 `qwen2.5:7b`** | — | 生成模型 | 约 **4.7 GB**，由启动脚本自动下载 |

> **不需要**：显卡（CPU 也能跑，只是慢些）、云服务账号、API Key、数据库。

---

## 二、部署步骤

### 第 0 步：确认文件完整

解压项目后，目录里应当有这些内容：

```
yidongbei-2.2\
├── start.bat          ← 部署入口
├── stop.bat
├── server.js
├── README.md
├── demo\index.html
├── package.json
└── .agents\skills\wenlv-assistant\   ← 技能包（含样本库）
```

**✅ 预期结果**：能看到 `start.bat` 和 `server.js`。若缺少，说明压缩包不完整。

---

### 第 1 步：安装 Ollama

打开 PowerShell 或 CMD，执行：

```bat
winget install Ollama.Ollama
```

安装完成后重新打开一个终端，执行以下命令验证：

```bat
ollama list
```

**✅ 预期结果**：能打印出模型列表（首次可能是空表头），说明 Ollama 已可用。

> 如果提示"未找到命令"，请**重开终端**（新装的命令需要新会话才能生效），或重启电脑。

---

### 第 2 步：一键启动（核心步骤）

双击项目根目录下的 `start.bat`。

脚本会自动完成四件事：

1. 检查 Ollama 是否安装
2. 检查 Node.js 版本是否 ≥ 18
3. 检查模型 `qwen2.5:7b`，缺失则自动下载（首次约 4.7 GB，请耐心等待）
4. 启动本地服务器，确认端口就绪后自动打开浏览器

**✅ 预期结果**：看到如下输出，并且浏览器自动打开页面：

```
================================================
   文旅智能辅助 Skill · 本地大模型启动器
================================================

[启动] 正在启动本地服务器 ...
[完成] 服务已在后台运行，页面已打开。
       停止服务：双击 stop.bat
```

浏览器打开的地址应为：**http://localhost:8000**

> ⏱️ **首次启动较慢**：需要把 4.7 GB 的模型加载进内存，且第一次生成要等模型加载，
> 后续请求会明显加快。

---

### 第 3 步：验证部署成功（3 项自检）

在浏览器页面（http://localhost:8000）上确认：

| # | 检查项 | ✅ 预期结果 |
| --- | --- | --- |
| 1 | 页面能否打开 | 出现「🏔️ 文旅智能辅助 · 演示界面」，有"方案规划 / 营销素材生成"两个标签 |
| 2 | 顶部状态徽标 | 显示 **🟢 本地大模型 qwen2.5:7b 已就绪**（不是黄色的"未检测"） |
| 3 | 能否生成 | 点「生成方案」，约 **20~40 秒**后出现完整的行程方案 |

若第 2 项显示的不是绿色，请跳到第五节「常见问题排查」。

---

### 第 4 步：试用两大核心功能

**功能一：个性化方案规划**

1. 在「方案规划」标签页填写：目的地、天数、预算档位、同行人群、兴趣偏好、饮食禁忌
2. 点击「**生成方案**」
3. 等待生成完成后，结果区会出现含「行程总览 + 逐日行程 + 费用预估 + 替代方案」的完整方案
4. 可点「**导出 Markdown**」保存到本地

**功能二：文旅营销素材生成**

1. 切到「营销素材生成」标签页
2. 选择产品类型、目标平台（朋友圈/小红书/抖音/OTA/公众号）、客群、风格
3. 点击「**生成文案**」，会输出 A/B 两个版本（理性卖点版 + 感性情绪版）

**附加演示：异常处理（建议评审时现场演示）**

| 操作 | 现象 | 对应能力 |
| --- | --- | --- |
| 点「**🤔 让 AI 先问我**」| 模型不生成方案，而是**一次性列出所有需求字段和可点选选项** | 信息缺失 → 集中追问 |
| 把目的地改成**样本库未覆盖的城市**（如"厦门"） | 退回通用文旅知识生成 | 目的地不在库 → 降级处理 |
| 选**样本库已覆盖的城市**（杭州/苏州/成都/丽江/西安） | 推荐项**逐条来自本地样本库** | 样本库驱动生成 |
| 生成完成后看结果区**顶部黄色告警条** | 会标注"哪些推荐未能在样本库中核实" | 输出质检 |

---

### 第 5 步：停止与重启

| 操作 | 方式 |
| --- | --- |
| 停止服务 | 双击 **`stop.bat`**，或运行 `taskkill /IM node.exe /F` |
| 重新启动 | 再次双击 `start.bat`（服务已在运行时，脚本会直接打开页面，不会重复启动） |

## 三、部署成功的判定标准（速查表）

全部满足即视为部署成功：

- [ ] 双击 `start.bat` 后浏览器自动打开 http://localhost:8000
- [ ] 顶部徽标显示绿色「本地大模型 qwen2.5:7b 已就绪」
- [ ] 点击「生成方案」能在 1 分钟内得到完整 Markdown 方案
- [ ] 「🤔 让 AI 先问我」按钮能输出带选项的追问清单

## 四、可选：接入 OpenClaw 引擎运行

本项目同时提供了符合 AgentSkill / OpenClaw 规范的技能包，可选地在 OpenClaw 引擎中加载运行。

```powershell
# 1. 安装引擎（约 1.1 GB）
npm install -g openclaw

# 2. 初始化配置与工作区
openclaw setup --non-interactive --accept-risk

# 3. 启动 Gateway（需保持运行）
openclaw gateway run

# 4. 安装本技能
openclaw skills install ./.agents/skills/wenlv-assistant

# 5. 查看状态（应为 ✓ Ready）
openclaw skills info wenlv-assistant
```

在 OpenClaw 控制台中调用本技能时，建议把命令直接写进消息（原因见
[`docs/OpenClaw-引擎集成验证报告.md`](OpenClaw-引擎集成验证报告.md) 问题 4、6）：

```
请执行这条命令并把输出原样展示给我，不要改写、不要复述技能文件：
node "<技能目录>/scripts/generate-plan.js" --city 杭州 --days 2 --budget 舒适 --crowd 情侣
```

> 完整的引擎集成验证记录（含 6 个实测发现的问题）见 **`docs/OpenClaw-引擎集成验证报告.md`**。

## 五、常见问题排查

> 排查顺序建议：**先看徽标状态 → 再看结果区错误信息 → 最后看 `server.log`**。
> 本项目的错误提示都写了具体原因和解决办法，多数情况照做即可。

| 现象 | 原因 | 解决办法 |
| --- | --- | --- |
| 双击 `start.bat` 窗口一闪而过 | 依赖检查未通过 | 用命令行运行 `start.bat`，即可看到停在屏幕上的错误原因 |
| 提示「未检测到 Ollama」 | 未安装或未加入 PATH | 执行 `winget install Ollama.Ollama`，**重开终端**后重试 |
| 提示「未检测到 Node.js」或「版本过低」 | 未安装或版本 < 18 | 到 [nodejs.org](https://nodejs.org) 安装 LTS 版，验证 `node -v` |
| 提示「服务未能启动，请查看 server.log」 | 端口被占用或启动异常 | 打开 `server.log` 看具体原因；或先双击 `stop.bat` 释放端口再试 |
| 徽标显示 **🔴 Ollama 未运行** | Ollama 服务没启动 | 启动 Ollama（开始菜单里找 Ollama），或命令行运行 `ollama serve` |
| 徽标显示 **🟠 模型未下载** | 缺少 `qwen2.5:7b` | 运行 `ollama pull qwen2.5:7b`（约 4.7 GB） |
| 徽标显示 **⚫ 本地服务未启动** | 浏览器打开的页面没有对应后端 | 双击 `start.bat` 启动服务后刷新页面 |
| 生成时提示「已等待 N 秒」很久 | 首次调用要把模型加载进显存 | 属正常现象，耐心等待；可先执行一次 `ollama run qwen2.5:7b` 预热 |
| 生成失败提示「模型返回为空，请重试」 | 偶发的小模型空回复 | 再点一次「生成方案」即可 |
| 结果区顶部出现**黄色质检告警** | 模型输出中有未能核实的推荐项 | **这是正常的保护机制**：说明系统已核对样本库并如实标注，按提示人工确认即可 |
| 双击 `.bat` 显示中文乱码或报「不是内部或外部命令」 | `.bat` 文件被编辑器以 UTF-8 保存了 | 用记事本"另存为"并选 **ANSI/GBK** 编码（详见 README「维护提示」节） |
