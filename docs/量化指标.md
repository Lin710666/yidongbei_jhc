# 量化指标

> 用于答辩演示与文档中说明成果。区分「可实测」与「预期（需上线验证）」，
> 请如实标注，避免夸大。

## 一、可实测的性能指标

| 指标 | 目标值 | 测量方式 |
|------|--------|----------|
| 规划生成耗时（规则引擎降级） | < 1 秒 | 后端计时（不含高德 API 网络延迟） |
| 规划生成耗时（Ollama 生成） | < 5 秒 | 本地 7B 模型推理 |
| 天气/POI 数据获取 | 依赖高德 API，单次 < 2 秒 | 接口耗时 |
| 前端首屏渲染 | < 3 秒 | 打包后静态资源体积 |

## 二、可用演示呈现的指标

| 指标 | 数值 | 说明 |
|------|------|------|
| 输入字段可留空比例 | 100% | 零门槛：全部字段可选填，后端默认值补齐 |
| 异常拦截覆盖场景 | 5 类 | 预算偏低 / 老人×特种兵 / 老人×爬山 / 儿童×特种兵 / 高龄×极低预算 |
| 跳转降级层级 | 4 级 | Scheme → 超时检测 → H5 → 复制口令 |
| 雨天备选（Plan B） | 自动替换室内 | 基于实时天气触发 |

## 三、预期指标（需上线验证，标注「预期」）

| 指标 | 预期 | 前提 |
|------|------|------|
| 客源转化率提升 | 预期 +X% | 需接入 OTA 预订与真实流量验证 |

## 四、演示建议

在演示视频/现场，用同一句话对比：
「带 80 岁老人特种兵游杭州，3 天，预算 2000」

展示：① 结构化画像抽取 → ② 系统**建议**调整节奏（用户可选择采纳/保持原样）→ ③ 实时天气 + 时间轴 + 地图轨迹 → ④ 点击 POI 一键跳转导航/点评/预订（含降级演示）。
