宣传片（视频背景）

主界面舞台与开屏**共用**这里的片子。上传后点卡片即可设为主界面背景， 或用卡片上的「开屏」按钮设为开屏背景。 支持 mp4（推荐）/ webm / mov，单个上限 —。
目录为空时，开屏与背景会自动用程序化绘制的西湖动态画面兜底，不会是一片黑。
也可以直接把文件放进 data/videos/，或从 B 站下载： npm run fetch:bili -- <BV号> 名字（连音轨一起下）。

片源是竖屏、或横拍被封装成竖屏时，这三种模式的观感差别很大。 旋转适合"横拍被装进竖屏文件"的片子；铺满裁剪适合竖屏 MV 填满横屏； 完整显示不裁任何内容，两侧用模糊的同段视频垫底。

开屏模板

开屏就一套「视频主页」。改动立即生效，下次进来就用新的。

配乐

默认用视频原声。上传宣传片时如果片子里有声音， 音轨会自动抽出来放进音频库，可以在这里换成别的曲子。

导出模板

导出方案时套用的版式。不传就用内置模板（封面 + 正文 + 页脚，可打印成 PDF）。 模板里用 {{title}} {{body}} {{date}} 等占位符；{{body}} 是必需项。模板只存在本机浏览器里。

视频从 data/videos/ 读取，本机文件、离线可用。 画面模式（旋转／铺满／完整显示）在上面「视频背景」一节里设置，开屏与主界面共用。
声音：受浏览器自动播放策略限制，开屏是先静音起播， 点开屏上的 🔊 即可出声；选「静音」会记住你的选择。

Blender 动画（可选：在 Blender 里生成移动动画并回传网页）

通过 MCP 驱动你已装的「MCP for Blender」插件，在 Blender 里建一个 会绕圈巡逻的小人、打好关键帧，导出 glTF 回传网页，用 three.js 的 AnimationMixer 播放。

需要 Blender 开着（在跑）。没开的话运行 npm run blender:start —— 会弹出 Blender 窗口，这是必须的：该插件的命令队列靠 Blender 主线程的定时器排空， 后台模式（blender -b）下命令永远不会执行。
动画是首尾闭合的：小人绕圈巡逻、朝向始终沿切线，所以循环播放时不会跳帧。
图片转 3D（可选：一张图生成三维模型）

用 TripoSR 把一张图片重建成带顶点色的三维网格，生成后自动加入 「外观 → 更换形象」的模型列表，可以直接选中查看。 全程在本机跑，图片不会上传到任何地方。

还没有选择图片。主体清晰、背景干净的照片效果最好。
越高越细，也越吃显存。默认 160 是"显卡上还有别的程序在跑"时的稳当档位； 显卡空着可以调到 256。想更省显存就把分块也调小。
权重约 1.6GB，用 npm run fetch:triposr 下载。
景区全景（可选：把景点变成能环视的三维场景）

用一张 360° 等距柱状全景图（宽高比 2:1）搭出可环视的景区场景， 再用单目深度模型把画面撑出起伏 —— 近处凸、远处退，是真正的立体浮雕。

需要先开启联网。注意：网上多数景点没有公开可用的等距柱状图 （中文全景平台不给直链），找不到时会明确列出试过哪些、为什么不行 —— 这时请用下面的「上传」或「程序化生成」。
上传的图会被量宽高比，不是 2:1 左右会明确告诉你（贴上去会变形）。
深度模型约 95MB，用 npm run fetch:depth 下载。
位置（可选：显示你在哪、景点在哪个方向）

位置只写进本机的 data/location.json，不上传。 浏览器定位需要你在弹窗里点一次授权；「IP 估算」会把请求发给第三方定位服务 （精度只到城市级），默认关闭。位置 MCP 服务读的就是同一个文件。

演示时手填坐标最省事：不用授权、结果也可复现。
内置坐标覆盖杭州 / 苏州 / 成都 / 丽江 / 西安的主要景点；表外地点需开启联网。
—
联网（可选：让模型能上网查资料）

开启后，模型遇到"最新票价 / 开放时间 / 天气 / 最近活动"这类问题时， 会主动调用搜索工具查证再回答，而不是凭训练时的旧记忆作答。 默认关闭；开启意味着你输入的查询词会被发往搜索引擎、相关网页会被抓取。

模型可以"搜索 → 读网页 → 再搜索"地连续查几轮。调大更彻底，但也更慢。
—
只允许 http/https 的公网地址；内网、本机（含 127.0.0.1 与 169.254.169.254 这类云元数据地址） 一律拒绝，重定向逐跳复检 —— 因为要抓的网址是模型生成的，属于不可信输入。
模型接入（可选：接外部大模型 API）

默认全部走本机 Ollama，不出网。想换成云端模型（DeepSeek / 智谱 / 通义千问 / OpenRouter / 任意 OpenAI 兼容端点）时在这里配置。Base URL 与 API Key 只写进本机的 data/providers.json，不会上传到任何地方。

填「根地址」就行：以 /v1 这类结尾，不要带 /chat/completions。带错了会自动截回。
多数厂商只有对话接口，没有视觉。勾了却没填模型名时会自动回落本机。
换向量模型后，旧向量不再参与语义检索（不同模型的向量不可比），关键词召回不受影响。
对外开放（可选：把本项目当 API 给外部调用）

开启后，AIRI 等外部程序可以用标准 OpenAI 兼容接口调用本项目的对话与文旅能力。 默认关闭；一旦勾上「记忆 / 角色卡」，就等于把这些数据交给持有令牌的一方，请按需勾选。

明文只在生成的那一刻显示一次，之后只保留打码版本。

打开后，输入框旁边会出现 🎤：录一段话，用本机 Whisper 转成文字填进输入框。 全程离线，音频不会发到任何地方。默认关闭，因为要用约 1GB 的模型权重。

—

没有权重时先跑 npm run fetch:whisper（约 1GB，走 hf-mirror 镜像）。 嫌大可以设 WHISPER_MODEL=openai/whisper-base 换更小的模型。
